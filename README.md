# Post a GTA 6 meme on X

Entry for the make.fun bounty "Post a GTA 6 meme on X" (https://make.fun/bounty/gta6-meme-x-01): an AI agent made a
GTA 6 meme with make.fun's ghost mascot and name worked into the picture, it was posted on X from a public account, and
this repository hands in the post's address via POST.json. The post is the entry; main.ts copies POST.json to /output.
